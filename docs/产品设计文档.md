# 「流境」产品设计文档

> 基于Vue的沉浸式流动自习室系统的设计与实现（融入AI陪伴智能体）
> 版本：v0.1 ｜ 日期：2026-11-11 ｜ 状态：方向定稿，待立项细化

---

## 1. 产品概述

「流境」是一款面向学生与自主学习者（高考/考研/考证/自习人群）的**沉浸式流动自习室**Web 应用。核心思路是：用视觉与听觉营造沉浸氛围（Canvas 流动场景 + 环境音效），用番茄钟与任务体系支撑专注流程，用数据记录与统计沉淀学习行为，并引入 AI 陪伴智能体「月见」提供情境化的陪伴、提醒与激励。

**一句话定位**：一个"看得见氛围、陪得了情绪、留得下数据"的线上自习室。

## 2. 目标用户与使用场景

| 用户群体 | 典型场景 | 核心诉求 |
|---|---|---|
| 考研/考证学生 | 图书馆替代，在家长时间自习 | 专注氛围、时长记录、打卡激励 |
| 高中生 | 晚自习、周末自主复习 | 仪式感、任务清单、陪伴感 |
| 自律困难者 | 容易刷手机、难以开始学习 | 低门槛进入、氛围带动、AI 督促 |

## 3. 设计理念

1. **流动性**：6 个流动场景（樱花 / 星座 / 霜花 / 萤火虫 / 深海 / 秋日）基于 Canvas 粒子算法实时渲染，氛围随时间与季节切换。
2. **陪伴感**：AI 智能体「月见」不是通用聊天机器人，而是能读取用户学习数据（今日时长、连续打卡、任务完成率）注入上下文，输出"知道你在干什么"的陪伴。
3. **数据沉淀**：每一次自习都自动记录，形成个人学习画像与成长轨迹。

## 4. 整体架构

```
前端层  Vue 3 + Pinia + Vue Router + Vite
        用户模块 | 自习核心 | 沉浸式场景 | AI陪伴·月见 | 数据统计(ECharts)

后端层  Node.js + Express（RESTful API）
        用户认证(JWT) | 学习记录 | 统计分析 | AI代理(prompt工程·上下文注入)

数据层  MySQL（用户·记录·统计） | 大模型API（月见对话） | 静态资源（场景素材·音效）
```

## 5. 功能规划（P0 → P2）

### P0 核心闭环（保底必做）

| 模块 | 功能点 |
|---|---|
| 用户模块 | 注册 / 登录（JWT）、个人资料、学习偏好设置（默认场景、音效、时长） |
| 自习核心 | 番茄钟 / 自定义倒计时、任务清单、开始/暂停/结束、浏览器标签页标题实时同步 |
| 沉浸式场景 | 6 个 Canvas 流动场景可切换、环境音效、全屏专注模式 |
| 数据持久化 | 每次自习记录入库（时长、场景、任务完成情况） |

### P1 创新增强（论文创新点）

| 模块 | 功能点 |
|---|---|
| AI 陪伴·月见 | ① 开工/收工问候与陪伴语；② 学习中提醒（久坐、鼓励）；③ 情绪支持对话（大模型 API + 角色设定）；④ 基于历史数据的学习总结/周报 |
| 数据统计 | 日/周/月学习时长报表、连续打卡天数、专注时段热力图（ECharts） |
| 激励系统 | 成就徽章、成长值，与月见陪伴语联动 |

### P2 可选扩展（时间充裕再做，否则写入论文"展望"）

- 同桌 / 自习室大厅（在线状态、排行榜）
- 后台管理端（用户管理、场景配置、数据看板）
- 移动端适配 / PWA

## 6. 月见（AI 陪伴智能体）设计要点

- **人设**：温柔安静的陪伴者，语气克制不聒噪，尊重用户的专注状态。
- **保底方案（不依赖外部 API）**：基于规则的固定陪伴语库 + 打卡/时长触发文案，保证系统在无 API 情况下依然完整可用。
- **增强方案（大模型 API）**：后端 AI 代理服务将用户画像（今日时长、连续天数、任务完成率）注入 system prompt，实现情境化对话；对话历史短期记忆，控制 token 预算。

## 7. 技术栈汇总

| 层次 | 选型 |
|---|---|
| 前端 | Vue 3（组合式 API）、Pinia、Vue Router、Vite、ECharts |
| 后端 | Node.js、Express、JWT 鉴权 |
| 数据库 | MySQL |
| AI | 大模型 API（对话生成）+ prompt 工程上下文注入 |
| 可视化 | Canvas 2D 粒子系统（6 个流动场景） |

## 8. 里程碑（建议节奏）

| 阶段 | 内容 | 产出 |
|---|---|---|
| M1 立项 | 项目档案、任务拆解、Vue 3 脚手架 | 可运行的空壳工程 |
| M2 P0 闭环 | 登录 → 自习 → 数据入库 → 统计展示 | 功能完整的核心版本 |
| M3 场景迁移 | 6 个 Canvas 场景组件化迁移 + 音效 | 沉浸式体验完整 |
| M4 月见 AI | 固定陪伴语保底 → 大模型 API 增强 | AI 陪伴可用 |
| M5 P1 完善 | 统计报表、激励系统、细节打磨 | 论文演示版 |
| M6 收尾 | 测试、部署、论文素材（截图/数据） | 答辩就绪版本 |

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 功能贪多做不完 | 严格按 P0 → P1 → P2 顺序，P0 闭环优先保底 |
| 大模型 API 不稳定/收费 | 月见采用"规则陪伴语保底 + API 增强"双轨设计 |
| 原生代码迁移成本 | Canvas 场景算法整体平移为 Vue 组件，外壳重写、内核保留 |
